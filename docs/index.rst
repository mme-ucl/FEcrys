FECrys documentation
====================

FECrys combines molecular simulation, internal-coordinate representations,
normalising flows, and statistically rigorous free-energy estimators for
molecular crystals.

The documentation is organised around two complementary views:

* :doc:`architecture` connects the architecture in Figure 1 of the manuscript
  to its implementation; and
* :doc:`api/index` lists every active class and function, including signatures,
  docstrings, and direct GitHub source links.
